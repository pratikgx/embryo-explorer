# Contributing

Open an issue for a bug, an anatomical correction or an interaction suggestion. For a bug, include your browser, screen size and the steps that reproduce it. For a scientific correction, identify the developmental stage and structure and link a primary paper or authoritative embryology reference.

For code changes, fork the repository and open a pull request explaining what changed and how you checked it. Run the app locally using the README instructions. Check the affected stages, forward and reverse exploration, selection and reset; include a compact-screen check for layout changes.

Keep anatomy and text specific to each stage. Distinguish human development from the mouse research challenge and label schematic features honestly. Add sources to `dist/anatomy-matrix.md` and document any new assets and their licenses in `THIRD_PARTY_NOTICES.md` and `dist/CREDITS.txt`.

Do not commit credentials, raw licensed music or assets without redistribution rights. Contributions of original code and assets should be available under this project’s MIT license; clearly identify any third-party exceptions.
